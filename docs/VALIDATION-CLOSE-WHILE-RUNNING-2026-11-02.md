# 后台任务运行时关闭窗口：Windows 回归（2026-11-02）

## 问题与边界

原桌面端在后台操作中拦截窗口关闭：本地检查只能等待后重新点击关闭；发布页面可以请求取消，但操作结束后仍需用户再关闭一次。此行为不会丢失数据，却容易被误认为程序卡住。修复仅涉及 PySide6 窗口生命周期，不触碰 GeoServer、GIS 源文件或凭据持久化逻辑。

## 修复行为

- **本地检查和 GDB 转换**：尝试关闭时明确询问是否在当前操作自然结束后自动关闭。选择否继续停留界面；选择是不会强制终止子进程或工作线程，也不会启动等待队列里的后续 GDB 转换。
- **发布任务**：尝试关闭时询问是否请求安全取消，并在工作线程结束后自动关闭。取消只在引擎的安全检查点生效，当前网络操作可能仍需等待超时；不以线程强杀掩盖远端写入结果未知的风险。
- **结果处理**：用户要求自动关闭后，后台成功或失败回调不会再弹出确认框阻碍窗口关闭；线程结束后由主 UI 事件循环调度一次普通 `close()`，关闭时清理会话凭据。
- **不改变**：任务日志的持久化、未知写入结果的人工核对策略、GeoServer 资源所有权校验、源数据只读原则。
