# P0-C 执行提示词｜离线真实图幅边界只读验收

Ponytail 原则：以现有 `sheet_split.py` 已验签产物和自带 GDAL SQLite/GEOS 空间函数为核心，不写新拓扑库、不引入 Python GIS 依赖、不连接数据库/服务器。

本阶段实施目标：
1. 本地选择分幅成果目录 `sheet-split-manifest.json` 和一份人工批准、坐标系一致的标准图幅范围 SHP（面或多面）及明确图幅编号字段。
2. 只读核对边界面非空、真实多边形、有效、逐编号唯一、没有图幅遗漏，按 GeoServer 出版前的安全规则校验所有已分幅图层的实际要素几何是否完全被对应图幅面覆盖（边界上的点也算合法）。使用本机 GDAL SQLite `ST_Covers`、`ST_IsValid`，不得只比较外包矩形。
3. 任何越界、空几何、坏边界、EPSG 不匹配、资料修改、GDAL 缺少 SQLite/GEOS、图号不一致或查询错误均应阻断“边界通过”结论；返回不合格数，所有结果仅落本机全新审计目录，不能触发发布和数据库写入。
4. 保留 SHA-256 对当前分幅清单、真实分幅组件、标准图框组件的引用；原数据不修改，不归档或上载实际几何内容。
5. 桌面端尽量保持现有简洁页面，以“更多工具”新增一个验收入口；只让用户选完成的分幅文件夹、边界文件和字段，报告突出是否通过和不合格数，不将“属性分幅”描述成地学边界裁剪。
6. Windows 3.13.3 GDAL + 合成点/面边界做几何测试，特别覆盖外包矩形内但多边形外的点、边界上的点、空值、无效图框和漏图号。Linux 仅做本机/CI 兼容代码，无远程登录和真实现场数据。
7. 先全量测试后提交 PR；桌面快捷方式与便携包只有在验证通过后才替换，旧版本回退目录必须保留。Linux 无本地完整运行时则只交付可审查的 CLI 方案，不能宣称存在已验证的自包含 Linux 安装包。

严格禁止：联网处理地质数据、访问现场 Linux 主机、访问现场 PostgreSQL、猜测地质图幅字段/边界、用外包矩形代替真正几何相交分析。
