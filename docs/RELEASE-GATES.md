## 下一项实现：多 TIFF 候选识别

保留明确的独立 GeoTIFF 发布能力，同时在文件发现与任务规划之间加入导入分类：

1. 保留明确选择的文件、目录和相对层级，识别可能属于同一个服务的数据组。
2. 结合目录配置、层级和已有影像元数据给出 Mosaic/Pyramid 候选及原因。相同 CRS 或分辨率只作为线索，不能据此断言应拼接。
3. 多个独立 TIFF 需要明确确认“按 N 个独立图层发布”；将选择和目标数量写入冻结计划。
4. 候选拼接/金字塔服务显示当前不支持并阻断。明确的 Pyramid 目录不能通过通用“忽略警告”静默展开；单独发布其中影像需重新选择具体文件。
5. 不把候选服务的辅助 SHP 索引误当业务图层。恢复任务时复用已确认意图，不能重新推断后改变资源列表。

最低验收样例：两个独立 TIFF 可在明确确认后形成两个图层；连续切片目录未选择模式时没有写请求；Pyramid 目录不会生成重复覆盖图层；辅助索引被隔离；恢复后选择与图层数量不变。该任务不要求同时实现完整 Mosaic/harvest/Pyramid 发布引擎。

## 已有保护的准确含义

### 失败补偿

`run_plan()` 会记录失败、部分完成或需要人工核对；没有自动调用回滚。`rollback_plan()` 是单独授权的配置清理，删除前核验全部对象，遇到外部变更或未知写结果会停止，并保留服务器实际文件。

这提供了一部分安全恢复能力，但不能宣称任意阶段都能自动恢复到原状态。后续自动补偿只应针对预授权、结果已知、本任务创建且未被外部修改的对象；未知结果必须继续保留核对路径。

### WMS 判空

可见且非均匀的 PNG 通过当前技术检查，只证明收到可解码的非空图像。它不能单独证明地理范围、样式或业务内容正确。固定整体范围和 512 像素请求也未覆盖所有比例尺、稀疏数据和有效窗口情况。

### 任务迁移

当前摘要覆盖绝对路径，任务库保存完整计划，执行前还要核验原源文件。修改盘符或手工重算摘要不是受支持的迁移方式。跨平台安装与同一任务跨平台恢复是不同验收项。
