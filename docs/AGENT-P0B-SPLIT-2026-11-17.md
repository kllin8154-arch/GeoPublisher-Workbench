# P0-B 第二阶段｜离线 SHP 按真实图幅字段拆分（Ponytail）

## 执行提示词
你是有地质数据发布经验的资深 GIS 工程师。不要为“批量”而堆砌新框架。以现有 GDAL 3.13.3、不可变的转换报告、业务目录审核与中文 PySide6 界面为基础，最小增量解决：单个 SHP 中不同真实图幅 ID 的要素分离，形成可审查、可继续发布的独立 SHP。

安全协议：
- 离线主机运行，不使用互联网、云上传、远端转换或在线服务；只允许用户主动选中的本地普通 SHP（拒绝 UNC 和符号链接）。
- 要求用户明确输入/选择“经人工核实”的实际字段名。候选字段只用于搜索线索，不能由软件自动推断或授权。
- 先对 SHP 做只读分幅枚举：计算非空、不重复的编号值与记录数，控制最多 100 幅，超限/空值/非法 ID/不支持类型必须阻断，不悄悄跳过无编号要素。
- 新输出文件夹必须不存在，位于原 SHP 外部。原始 SHP、DBF、SHX、PRJ、CPG 不修改、不删除、不覆盖。GDAL 子进程 shell=False，只读输入，明确编码、超时和私有环境。
- 每个图幅的要素数量验证、字段列表一致性、EPSG/范围明确验证；总要素数 = 所有子集要素数且严格不为零。收集 JSON 本地审计报告并记录所有产物 SHA256。中途失败保留隔离结果但不得标记成功，也不得批量加入发布队列。
- 输出分幅 SHP 可手动审核后按原有“选择 SHP / 下一步检查 / 确认发布”路径使用；如来源是经过校验的 GDB/MXD，尽量保留原来源关系用于后续正确父子节点审核。
- 增加友好的图幅拆分 GUI 入口、中文差错/下一步提示、合理按钮尺寸和深浅主题，不改现有默认流程。
- 只用合成几何数据集做端到端实测，另用纯单元测试覆盖：SQL 引号/注入字符、混合空值、图幅超限、改动源文件、重复输出路径、编码、单图幅、取消与转换失败、图幅值归组。
- Windows 先运行完整 pytest + Ruff，再按现有离线脚本构建包和 SHA256 验证；更新原桌面快捷方式并保留回退备份。

范围外：本轮不按行政区/空间网格自动剪裁，不隐式做地学拓扑重构；图幅编号属性分组 != 经过地质人员审核的图幅边界。入库需另外人工 WMS 与现有数据库核验。
