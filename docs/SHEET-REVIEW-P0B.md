# P0-B｜GDB/MXD 真正图幅归组（离线人工审核版）

## 为什么需要这一步

**一个 GDB/MXD 文件包含多个要素类，不代表每个要素类就是一张地质图幅。** 同一图幅可能同时包含地层面、断层线、注记等多个图层；反过来，一个要素类也可能跨多个标准图幅。当前软件只能自动识别原文件与 GeoServer 图层的关系，绝不凭文件名或字段名冒充完整图幅识别。

**分幅衔接：** 如果一个 SHP 内确实包含多个图幅编号，先按 [P0-B 离线属性分幅](FIELD-SHEET-SPLIT-P0B.md) 以人工审核字段将要素拆分；拆分后才进入下面的“逐图层审核真实图幅关系”步骤。

## Windows 工作台操作

1. 选择整个 GDB / MXD → 完成本地转换 → 点击“下一步：检查图幅”。
2. 当计划包含 GDB/MXD 来源时点击 **核对图幅关系**。表格展示**来源文件、原始图层、候选图幅字段**。候选字段如 `SHEET_ID`、`MAP_NO`、`TFBH`、`图幅编号` 等仅作检查线索，软件不读取并据此直接判断图幅归属。
3. 核实实际属性和空间范围后，为一个图层填入唯一的 **图幅编号、图幅名称**，选择 **已核对：该图层属于一张图幅**。来自**同一来源文件**、属于**同一张真实图幅**的多个图层，填写**相同的编号及名称**；可以用 Ctrl/Shift 多选后点击 **将选中图层归入同一图幅**。可用搜索框过滤大量图层。
4. 若一个图层包含多张图幅，选 **需拆分：该图层跨多张图幅**；若不确定，保持 **待核对**。这两种状态可以保存本地审阅记录，但不能用它生成“已确认图幅”分组；必须先对原始数据副本按已核实的图幅字段拆分并核对数据数量和空间范围。禁止直接把整个图层登记成一张图幅。
5. 点击 **保存本地图幅关系**，工作台在本机创建全新 `sheet-review-*.json` 文件，包含原 `plan.json` 的 SHA-256、任务 ID、源文件、图层标识和候选字段。记录不覆盖旧审阅版；支持再次载入历史审阅版修改。
6. 发布完成并验收 WMS 后点 **生成数据库目录草稿**，如果当前审核清单完整通过，会生成分组目录；否则明确阻断并提示继续处理。通过 CLI 也可执行：`geopub sheet-review plan.json --output new-sheet-review.json`；编辑审核信息后用 `geopub catalog-draft plan.json --sheet-review reviewed.json --output new-catalog-dir`。

## 真实关系与目录结构示例

```text
待分类（仅本地审核容器，注册数据库前须替换）
└── 来源文件：基础地质.gdb  ← 该原文件的父节点（待审核）
    ├── 图幅：H49E001006     ← 真实图幅对应的子节点（人工声明、待审核）
    │   ├── 地层面         ← GeoServer 的单独 WMS 图层
    │   └── 地质界线       ← GeoServer 的单独 WMS 图层
    └── 图幅：H49E001007
        ├── 地层面_007
        └── 地质界线_007
```

“真实图幅”必须是图层上一级，以便一张图幅包含多个 GeoServer 图层。实际业务目录还要将来源父节点放到正确 **专题 → 比例尺** 节点下。所有新组 `classification_reviewed=false`，GDB/MXD 子图层 `conversion_reviewed=false`，WMS 默认 `PENDING`，数据库 `schema_verified=false`。**人工填写图幅编号不等于空间边界自动验证，也不会批准数据库写入。**

## 非法输入与失败恢复

- 清单与原 `plan.json` SHA256、任务 ID、资源 ID、原文件或候选字段不一致，图幅编号含路径符号、同编号不同名称、同一图层需拆分或未确认：阻断采用图幅清单生成已确认目录。
- 同名图幅但源文件不同，必须生成**两个独立**图幅节点，不跨来源合并。
- 生成目录仍只在本机写 JSON，**不修改** GeoServer 或 PostgreSQL；受控数据库登记继续走既有只读预检、WMS 人工验收、明确授权和事务回查。
- 本轮尚未自动将一个包含多张图幅的 SHP 按字段切分，也未生成复合图层的 GeoServer 图层组/单一 WMS；该功能属于下一子阶段，必须使用合成数据和独立离线验收。

## 外观适配

桌面端新增 **环境设置 → 界面主题 → 跟随系统 / 浅色 / 深色**。颜色采用同一墨绿色品牌色、对比度适配的文字/边框/禁用态；普通操作按钮最小约 38px，高频数据来源按钮约 48px。中等窗口宽度下“更多工具”换为两行，数据导入区支持滚动。主题首选项仅保存在本机工作目录的 `ui-preferences.ini`，不包含账号密码。
